# Juego del Ahorcado en Python

## Descripción
Proyecto desarrollado en Python que consiste en un juego del ahorcado. El programa selecciona una palabra aleatoria y el jugador debe adivinarla letra por letra antes de quedarse sin intentos.

## Funcionalidades
- Selección aleatoria de palabras.
- Ingreso y validación de letras.
- Visualización de las letras descubiertas.
- Sistema de intentos limitados.
- Mensaje final de victoria o derrota.

## Tecnologías
- Python
- Módulo `random`

## Objetivo
Practicar los fundamentos de Python, incluyendo variables, listas, ciclos, condicionales, cadenas de texto y generación de valores aleatorios.
